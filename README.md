# 🐦 Identificador de Aves con IA

Clasificador de especies de aves basado en el dataset **CUB-200-2011**, utilizando una red neuronal convolucional (CNN) con Transfer Learning.

## ✨ Características

- 🎯 Clasificación de **200 especies de aves** diferentes
- 🤖 Modelo basado en **EfficientNetB4** con Transfer Learning
- 🌐 Interfaz web intuitiva con **Streamlit**
- ⚡ Descarga automática del modelo en la primera ejecución
- 📊 Visualización de confianza y Top-5 predicciones
- 📱 Diseño responsive (funciona en móvil y escritorio)
